## Data Flow (After Changes)

```
Topic { seoKeywords[] }
        │
        ▼
Content Processing
  → Fetch topic keywords
  → Generate summary + seoTitle (using keywords)
  → Store in ProcessedContent
        │
        ▼
Translation
  → Translate title, seoTitle, summary, content
  → Store in Translation
        │
        ▼
UI Display
  → Show metadata card with SEO title, summary, quality, topic
```
